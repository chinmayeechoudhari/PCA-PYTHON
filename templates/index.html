Train / Test Split

In machine learning, data is always split into two groups. The training set teaches the model. The test set is kept hidden and used only to measure how well the model works on new, unseen data. This is how we know if a model truly learned or just memorised.

Anomaly Detection

The model learns what normal images look like. Unusual images cannot be reconstructed well — their error (MSE) is high. We flag images above a threshold as anomalies. This technique is used in quality control, fraud detection, and medical imaging.

Threshold = mean_train_error × multiplier. Higher = fewer anomalies flagged.
